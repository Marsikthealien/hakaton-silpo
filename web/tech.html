Чого MCP «Сільпо» не дозволяє

Склад товару. get_product_details.attributes — країна, ТМ, продавець, БЖУ. Інгредієнтів немає, тож алергени ловимо за назвою.

Активацію промо. get_my_promos лише читає.

Спосіб оплати. В update_shopping_cart немає paymentType — Дольки обирає людина.

Вподобання родини. get_my_family дає склад, але не смаки.

Сертифікати. get_my_certificates відповідає 500 Internal Server Error — схоже на баг на боці «Сільпо».
